# CESMII-Simantha-Dashboard
A visualization tool on systems level with various monitoring aspects such as health index and productivity status of machines based on the simantha simulator by M. Hoffman

# Details:
This application was developed and integrated as a part of CESMII's SMIP and SM Marketplace by leveraging TAMU SMART’s data ingestion pipeline
