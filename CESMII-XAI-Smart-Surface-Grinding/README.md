# CESMII-XAI-Smart-Surface-Grinding
Explainable AI (XAI)-driven vibration sensing scheme for surface quality monitoring in a smart surface grinding process

# Details:
The global market size for grinding processes is estimated to be several billion dollars with their presence in multiple SMEs. We set up an explainable AI (XAI) driven vibration sensing schema based on COTS accelerometer sensor to enable surface quality monitoring in precision surface grinding machine at the University of Texas Rio Grande Valley (UTRGV).
